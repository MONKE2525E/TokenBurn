# Product

## Register

product

## Users

Windows developers who use multiple AI coding providers and want to glance at quota, reset time, and local spend without opening a browser or copying usage data to a service.

## Product Purpose

Usage Monitor is a local-first Windows dashboard and taskbar companion inspired by OpenUsage's compact macOS popover. It should make the current quota obvious in one glance, open the full dashboard from the taskbar or tray, and remain useful when a provider is offline or stale.

## Brand Personality

Quiet, precise, trustworthy. The interface should feel like a polished system utility, with enough warmth and motion to make refreshes understandable without becoming decorative.

## Anti-references

Do not look like a generic SaaS analytics dashboard, a neon gamer overlay, a copied macOS menu bar, or an unreliable shell hack presented as a guaranteed Windows feature. Do not invent zero usage or expose credentials.

## Design Principles

- Put the most actionable quota and reset information at the point of glance.
- Prefer supported Windows behavior for the primary open path, with experimental shell integrations isolated and clearly labeled.
- Keep OpenUsage's provider grouping, progressive disclosure, spend ring, and customization model recognizable.
- Make stale, unavailable, and estimated data explicit rather than silently smoothing it over.
- Motion should explain state changes, not delay access to the information.

## Accessibility & Inclusion

Support 100% to 200% DPI, keyboard activation for every control, high contrast, reduced-motion-friendly transitions, readable contrast, and state communication that does not rely on color alone.
